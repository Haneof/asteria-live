# 验收门禁 — ACCEPTANCE.md

> 阶段门禁、测试条件与验收证据。只有存在实际实现与测试证据才能通过。

## 阶段门禁

| 阶段 | 门禁条件 |
|------|----------|
| G0 | 治理文件真实存在、规则一致、git 状态干净或改动受保护 |
| G1 | 干净环境可安装；启动、健康检查、单元测试、基本 CI 可执行 |
| G2 | 至少一次真实可重复闭环；明确真实/Mock 边界，不把 Mock 当真实性能 |
| G3 | 非法边拒绝；可调度动作有测试过的安全回归路径；路径搜索单元+集成测试 |
| G4 | 未验证资产不得进入正式调度库；能力等级与测试证据分开记录 |
| G5 | 无来源/过期商品事实不能用于商品陈述；脚本动作与音频时间线可追溯 |
| G6 | 不支持的平台功能明确降级；可转人工；不伪造平台接口结果 |
| G7 | 目标机实测 720p/25FPS、音画同步、显存峰值、端到端延迟、掉帧率、4–5 小时稳定性 |

## 证据要求

- 每条 PASS 必须关联：文件路径、测试命令、测试输出摘要、git commit。
- 未运行测试标 NOT RUN。
- 性能指标必须来自真实运行，禁止估计。
